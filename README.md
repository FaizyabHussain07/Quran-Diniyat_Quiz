# Quran-Diniyat_Quiz


**Project Overview**
-------------------

:book: The Quran-Diniyat_Quiz is a software project designed to test one's knowledge of the Quran and Islamic studies. This project is developed using HTML, providing a simple and interactive way to assess understanding of Islamic principles.

**Installation**
------------

:warning: This project does not require any installation as it is a simple HTML-based quiz. Simply open the `index.html` file in a web browser to start the quiz.

1. Clone the repository using Git:
   ```bash
git clone https://github.com/FaizyabHussain07/Quran-Diniyat_Quiz.git
```
2. Navigate to the project directory:
   ```bash
cd Quran-Diniyat_Quiz
```
3. Open the `index.html` file in a web browser to start the quiz.

**Usage**
-----

:book: To use the Quran-Diniyat_Quiz, follow these steps:

1. Open the `index.html` file in a web browser.
2. Navigate through the quiz interface to answer questions.
3. Use the provided buttons or links to submit answers and proceed with the quiz.

**Project Structure**
-------------------

:file_folder: The project consists of the following files and directories:

* `index.html`: The main HTML file for the quiz interface.
* `quran logo.PNG`: A PNG image file used as the logo for the quiz.
